# 線上展覽平台

完全免費、零安裝、可部署的 3D 線上展覽平台。策展人選展間模板、把影音／文字／圖片／3D 物件掛上去，觀眾用第一人稱（桌機＋手機）走進來看展。支援多帳號、多展覽。

## 檔案結構

```
exhibition-platform/
  index.html      首頁：帳號登入 + 我的展覽 + 公開展覽
  editor.html     策展編輯器：選模板、加展品、即時 2D 平面圖、自動儲存
  view.html       第一人稱觀展器（?id=展覽ID）
  js/
    store.js      資料層（目前 localStorage，可換 Firebase / Supabase）
    auth.js       帳號層（目前本機帳號，可換 Firebase Auth）
    templates.js  展間模板定義
```

三頁共用 `js/` 下的同一份資料層，邏輯與 UI 解耦。

## 怎麼跑

因為要跨頁共用資料，請用本機伺服器開啟（不要直接雙擊檔案）：

```bash
cd exhibition-platform
python3 -m http.server 8765
```

然後瀏覽器開 `http://localhost:8765`。手機測試：手機連同一個 Wi-Fi，開 `http://<你電腦的IP>:8765`。

## 操作

- **桌機**：按住滑鼠左鍵拖曳轉視角；`W` 前進 `S` 後退 `A`/`D` 左右；準心對準展品變黃後，放開點一下看介紹。
- **手機**：左下搖桿移動；滑右側畫面轉視角；走近展品時下方按鈕亮起，點一下看介紹。

## 使用流程

1. 首頁建立策展人帳號（本機，零設定）。
2. 「＋ 建立新展覽」→ 進編輯器。
3. 選展間模板，用「＋ 圖片／文字／影片／3D 物件」加展品，右側平面圖即時顯示擺放位置。修改自動儲存。
4. 「在 3D 中預覽」用第一人稱逛自己的展。
5. 回首頁「發佈」，展覽就會出現在「公開展覽」，可分享 `view.html?id=…` 連結。

## 各類展品

- **圖片**：填網址，或從電腦上傳（自動縮圖到 1024px 存本機）。
- **文字**：標題＋說明，渲染成牆上看板。
- **影片**：填 MP4 / HLS 網址（需開放 CORS）。建議用 Cloudflare Stream / Mux，**不要直接放大檔**；YouTube 連結無法當 3D 材質。
- **3D 物件**：填 `.glb` 網址，自動置中／縮放／旋轉。上傳前先做 Draco 壓縮、限制面數。
- **熱點／彩蛋**：空間中會發光脈動的點。觀眾走近點擊時彈出說明，並可播放語音導覽／音效（填音效網址）。

## 兩種編輯方式

- **表單編輯**（`editor.html`）：選模板、加展品、調參數，搭配 2D 平面圖，適合快速建置。
- **展場內編輯**（`view.html?...&edit=1`，或編輯器右上「✎ 在展場中編輯」）：擁有者進場後切到編輯模式，**直接在 3D 場景中點選展品、拖曳移動、換照片、改大小、刪除**，即時儲存。建議用電腦操作。

## 多房間（一個展覽 1~5 個展廳）

一個展覽可有多個房間，各自有獨立模板與展品。觀眾用頂部「房間」鈕切換；策展人在「⚙ 場景／房間」面板或表單編輯器的房間下拉新增、命名、刪除、切換房間。

## 材質與細緻度

道具採程序生成的**紋理材質**（非純色）：木製品有木紋、沙發／軟墊有布料織紋、壓克力件半透明、金屬反光（環境貼圖）。植栽為真實的**龜背芋裂葉**（帶孔洞的葉形貼圖）。

## 門戶看見另一個空間

放置「門戶」道具並設定通往的房間後，進場時系統會把每個房間各渲染一張即時畫面，貼到門戶的窗上——**站在門前就能看見另一個房間的實際 3D 樣貌**，走近自動進入。

## 道具／傢俱庫（30+ 種）

`js/props.js` 提供分類道具庫，皆為多部件程序生成：
- **展示**：展台（中/矮/寬）、玻璃展示櫃、壓克力展台、展示桌、懸吊看板、直幅布幔、掛卡展示架、門櫃展牆、隔板牆、說明立台、畫架、紅龍圍欄、層架展示櫃。
- **傢俱**：長凳、軟墊長凳、雙人沙發、茶几、裝飾立柱。
- **辦公**：辦公桌、辦公椅、書架、收納櫃、接待櫃台、桌燈、電腦螢幕。
- **植栽**：大型植栽、小盆栽。
道具可在展場中拖曳移動、旋轉、縮放、改主色。

## 策展人佈燈

新增「燈具」物件（投射燈），會真正打亮場景。可拖曳擺位、調離地高度、亮度、光束角度、**照射方向（水平 pan）與傾角（tilt）**、燈光顏色。（即時燈光上限 8 盞以兼顧效能。）落地燈、軌道投射燈也會發光。

## 房間門戶（走動切換）

放置「門戶」道具（動線分類）並設定「通往房間」，觀眾走近即自動進入該房間；頂部房間鈕仍可手動切換。

## 鎖定與掛載

- **鎖定**：任何物件（含上傳的）可在編輯面板按「🔒 鎖定」，鎖定後可選取但不會被拖動，防誤觸。
- **牆上展品自由吸附**：拖曳圖片／文字／影片時，可吸附到房間牆面或**隔板牆、層架、門櫃牆**等垂直面；按「↺ 貼回房間牆面」可還原。
- 天花板上的物件（懸吊看板、軌道燈、燈具）也可拖曳移動。

## 3D 模型格式與上傳

3D 物件支援 `.glb` 與 `.stl`。在「3D 物件」編輯面板可**填網址或直接從電腦上傳檔案**（自動置中、縮放、上材質）。沒有模型檔可到 poly.pizza 或 Sketchfab（篩選可下載／CC 授權）下載 .glb 再上傳。上傳檔存在本機，建議小於 3MB。

## 門戶貼牆 ＋ 圓角

- 門戶會自動**吸附貼齊到最近的牆面**並朝向房間內（不會浮在地板中央）；拖曳時即時換牆。
- 所有方塊類道具與展框採**圓角**（RoundedBoxGeometry），邊角不再尖銳。

## 真實感與場景設定

- **自然光**：斜頂天窗透入天空光，陽光與窗框格在地面投下**真實陰影**；PBR 環境反射讓金框、地板等材質更有質感。
- **木地板／水泥地**：依模板自動套用（木地板畫室、暖色畫廊為木紋）。
- **場景設定面板**（編輯模式右上「⚙ 場景設定」）：換模板、**逐面牆改顏色**、說明牌**字體**（黑體／襯線／圓體）、**預設展框材質**、**自然光強度與方向**、**背景音樂**網址。

## 照片級素材（assets/）

「低配模型感」的解法是換成真實素材，已內建：
- **HDRI 全景照片**（`assets/hdr/`）：同時當戶外背景與環境光照（IBL），所有材質得到真實反射。場景設定可切換「原野樹影／歐洲街景／程序天空」。
- **木地板 PBR 貼圖**（`assets/tex/`）：顏色＋凹凸＋粗糙度三張圖，真實木紋與光澤。
- **真實 3D 模型**（`assets/models/`，道具庫「真實模型」分類）：木框皮革沙發、絨面扶手椅、錦緞單椅、玻璃果盤展品。載入後快取，可多次擺放、拖曳、旋轉、縮放。
- 要擴充：把 CC0 的 .hdr / 貼圖 / .glb 放進對應資料夾，在 `HDRIS`、`GLB_INFO`（view.html）與 `PROPS.catalog`（props.js）登記即可。
- 授權與來源見 `assets/CREDITS.md`（Wayfair 模型為 CC BY 4.0，需標示）。
- 注意：真實素材約 28MB，首次載入較慢；上線前建議用 gltf-transform 做 Draco 壓縮、HDRI 用 1k。

## 基礎展覽空間（起始版型）

首頁「＋ 基礎展覽空間（建議起點）」一鍵建立，定義在 `js/starter.js`。20m×14m 採光藝廊，**順時針動線、15 個導覽站、4 個章節**：

| 區域 | 內容 | 設計重點 |
|---|---|---|
| 序章（南牆左、入口） | 展覽說明牌、導覽立台、壁燈、木格柵牆 | 進場先讀策展理念 |
| 第一章（西牆） | 4 件作品（橫直交錯） | 作品中心 1.5m、間距 2.7m |
| 第二章（北牆主視覺） | 中央 2.4m 大幅＋兩側小幅、兩盞投射燈 | 全場視覺核心，正對入口 |
| 第三章（東側立體區） | 3 座水泥展台＋真實模型、植栽、曲線長椅、吊燈、彩蛋 | 靠落地玻璃自然光 |
| 終章（南牆右） | 2 件收尾作品＋結語 | 回到入口、按讚留言 |

所有作品為佔位圖，點選後換上自己的圖／文字／模型即可。有填「說明文字」的道具（展台上的立體作品）也會成為可點選的導覽站。

## 數位原生策展：路線、章節、動線引導

- **進場選路線**：「策展導覽（推薦）」依策展人設計的順序與章節自動帶領；「自由參觀」自行探索。
- **章節敘事**：每件展品可設定「章節／展區」（編輯面板欄位）。導覽進入新章節時，畫面浮現章節標題卡。導覽列顯示「章節 · 第 n/N 件 · 標題」。
- **編號標記**：導覽中每個站點上方漂浮編號，當前站為金色。
- **地面引導光點**：流動的光點從腳下引到下一站，到站自動消失。
- **聚焦模式**：到站後畫面邊緣柔化，視線集中在作品；轉頭看作品不會中斷導覽，走動才會離開導覽。

## 採光藝廊模板與戶外環境

- 新模板「採光藝廊」：白牆、天窗，**整面落地玻璃牆**（東側）。
- **物理天空**（隨「光源方向」設定變化）＋戶外草地與樹林，從天窗與玻璃牆都看得到綠意。
- 每件牆上作品自帶**投射光暈＋燈條**（美術館打光感）。
- 新道具：**曲線造型長椅**（雕塑感 S 形）、**木格柵牆**。

## 小地圖與導覽

- **小地圖**：左下角即時俯視圖，顯示各展品與你的位置朝向；右上「🗺 地圖」可開關。
- **導覽動線**：右上「▷ 導覽」自動帶你依序走到每件作品正前方並彈出介紹；右下 ‹ › 上一件／下一件、結束。

## 立體展框與 3D 道具

- **立體展框**：畫框有真實厚度，可選黑框／白框／木框／金框／無框（全域預設或逐件覆寫）。
- **3D 道具／展架**：展台、高展柱、長凳、隔板牆、植栽，可在場景中**拖曳移動、旋轉、縮放**。

## 依尺寸縮放（橫式／直式）

編輯展品時可切換**橫式／直式**，並套用標準畫框尺寸預設（50×40 到 150×100 cm、80×80 正方），也可用滑桿微調寬高（公尺）。

## 訪客互動

- **按讚／留言**：每件展品（圖片／文字／影片／3D）都能按愛心、留言，像作品旁的留言牆。
- **熱點彩蛋**：策展人埋的發光點，點擊觸發說明彈窗與語音／音效。
- 目前互動資料同樣存在本機 localStorage；接上 Firestore 後即可跨裝置共享、即時累積。

## 注意事項（本機模式的限制）

- 資料、帳號、上傳的圖片都存在「這台瀏覽器的 localStorage」，**換瀏覽器或清快取就會不見**，也無法跨裝置共用。localStorage 上限約 5MB，上傳太多圖片會塞滿。
- 這是刻意的 MVP 設計：先零成本驗證體驗與策展流程。要正式上線再升級雲端（見下）。

## 上線與升級（都有免費額度）

- **靜態部署**：整個資料夾丟 Cloudflare Pages（推薦，流量免費）／ GitHub Pages ／ Firebase Hosting。
- **雲端帳號 + 跨裝置資料**：把 `js/auth.js` 換成 Firebase Auth、`js/store.js` 換成 Firestore（介面不變，其他頁不用動）。
- **素材**：圖片／GLB 放 Cloudflare R2（下載流量免費）；影片走 Cloudflare Stream / Mux。

## 後續可加

更多展間模板、烘焙光影、導覽動線、展品燈光、多人同行逛展（Colyseus / Liveblocks）、VR（Three.js WebXR，同一套程式可開）。
